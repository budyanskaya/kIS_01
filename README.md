# Отразите в 1С: ERP операции по приобретению ТМЦ и услуг, включая оформление документа заказ поставщику, поступление товаров, отражение возвратов товаров поставщику, корректировку заказа поставщику и корректировку поступления товаров. Приведите примеры отчетов данной подсистемы.
## Ход работы
### Оформление и оплата заказа поставщику. 
Создан документ «Приобретение товаров и услуг» на сумму 66 000,00 руб. с поставщиком «Икар». Введена информация об оплате: срок — 14.01.2026, сумма — 100%. Для оплаты создан расходный кассовый ордер.

### Формирование отчета
Сформирован отчет «Карточка расчетов с поставщиками» для анализа взаиморасчетов по конкретному заказу (№ 0000-000011 от 14.01.2026). Отчет наглядно демонстрирует полный цикл операций: от оформления заказа и поступления товаров до корректировки, частичной оплаты и возврата товара. Это позволяет отслеживать текущее состояние долга перед поставщиком и контролировать финансовую дисциплину по каждому контрагенту.
